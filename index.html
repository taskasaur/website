Devices and automations

Choose where the work runs.

Create a TypeScript automation on one device and select the approved computer that will run it. See the capabilities and plugins it needs before enabling it.

  • Per-item execution targets and on/off controls
  • Remote plugin installation on approved computers
  • Remote terminals on capable desktop and headless peers
  • Phones and browsers can control an approved host

Background work and terminal hosting depend on each device’s capabilities and local permission settings.

Portable workspaces

Your whole workspace.
One .taskasaur file.

Save records, tables, files, plugin credentials, and device connections together, with optional password encryption. Workspace history travels with the file so it can reconnect and synchronize later.

work.taskasaurYOUR WORKSPACE
  • Tables, records, and custom fields
  • Files and retained versions
  • Plugin data and shared credentials
  • Approved connections and sync history

Device identity, private settings, and caches stay on their own device.
